# PCL YYH 项目复查（2026-10-20）

本次针对完整项目的结构、构建、依赖与配置关联开展检查，重点复核下载鉴权、凭据保存、单文件程序集加载、Java 选择、JVM 参数和已删除页面的引用。主要使用场景为 Minecraft 1.20.1 + Forge。

## 已修复的问题

| 问题 | 处理 |
| --- | --- |
| CurseForge 鉴权客户端允许自动重定向，可能把 Key 带到跳转站点 | 禁用自动跳转，逐次跟随 HTTPS 跳转，仅向精确匹配的官方 API/CDN 主机添加 Key；跨站移除敏感请求头，限制跳转次数 |
| 内嵌程序集加载器按前缀匹配，可能把语言资源请求错误地解析为主 DLL | 改为匹配程序集的完整短名称，让缺失的语言资源正常回退 |
| G1 调优、预触碰内存和字符串去重全部默认开启 | 改为默认关闭，保留可选开关；不自动覆盖用户已经手动保存的值 |
| G1 调优固定 32 MB 分区、20% 新生代和 50 ms 停顿目标 | 堆布局由 Java 自适应；可选调优仅指定 100 ms 软目标和并行引用处理，明确不保证帧率或停顿时间 |
| Java 7 / Java 8 早期版本可能收到不支持的字符串去重参数 | 限定 Java 8u20 及以上；Java 17 路径已验证 |
| Forge 补丁差异、Minecraft 证书忽略被作为默认“优化” | 删除内置追加逻辑和补丁差异开关，避免将校验绕过作为性能设置 |
| HTTPS 证书验证选项可点击，但后台实际强制开启 | 后续优化已彻底删除此选项、配置键及自定义回调，使用 .NET 默认 HTTPS 证书验证 |
| 从版本独立 JVM 旧预设迁移时，可能误清空全局 JVM 参数 | 根据参数实际来源，仅清理对应范围的旧预设 |
| 个性化移除后残留恒假判断、无效启动按钮分支及旧 GC 设置 | 清理失效逻辑，保留版本隐藏（F11）与正常下载、启动、资源管理 |
| 项目目录产生游戏文件、日志和本地配置，可能误提交 | 根目录运行数据加入 Git 忽略规则；源码和必要的内置依赖保留 |

## 对 Forge 1.20.1 的设置建议

| 选项 | 建议 | 说明 |
| --- | --- | --- |
| Java | 64 位 Java 17 | Forge 1.20.1 官方基线；需要其他 Java 的特殊整合包可通过版本独立设置覆盖 |
| G1 垃圾回收 | 开启 | 常规起点，版本独立 GC 选项优先 |
| G1 停顿目标调优 | 先关闭 | 100 ms 是软目标，只有对比测试后再决定是否启用 |
| 启动时预触碰堆内存 | 关闭 | 会提前触碰初始堆页面，可能延长启动、增加内存压力；不等于无条件立即占用整个最大堆 |
| 字符串去重 | 先关闭 | 可能降低部分整合包的内存占用，同时增加后台 CPU 工作 |
| 关闭 JVM 性能共享内存 | 可开启 | 使用 jstat 等诊断工具时可关闭该选项 |
| 高性能显卡 | 可开启 | 向 Windows 请求优先选择高性能显卡，实际仍由系统和驱动决定 |
| 中文路径修复 | 保留开启 | 按系统编码与版本设置决定是否启用；自定义 javaagent 可能有兼容性影响 |
| LWJGL 修复 | 保留开启 | 仅针对 LWJGL 3.4.1 触发，1.20.1 通常不会触发 |
| HTTPS 验证 | 始终开启 | 无关闭入口 |

本机约 24 GB 内存，建议中等模组组合先试 6 GB 游戏堆，较重整合包再视实际占用尝试 8 GB。自动内存分配仍然可用；堆外内存、显卡驱动和其他程序也需要剩余空间。这是起始配置建议，并非性能保证。
